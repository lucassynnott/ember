# ember.appliedleverage.io

Ember's landing page: plain HTML, CSS and one module script, in the app's own palette.

- `index.html`, `styles.css`, `main.js`: the page. Download links point at the latest release's DMG, looked up from GitHub.
- `assets/`: the demo video, screenshots (WebP), the icon, Geist, and the app's Hairline line figures (`assets/fig`, MIT).
- `brag-output/`: the launch video's plan and share copy, made with the [/brag](https://github.com/latent-spaces/brag) skill. `work/` (frames, soundtrack script, composition) is not committed.

Deploy: `scripts/deploy.sh` (Cloudflare Pages project `ember-app`, through Composio).
